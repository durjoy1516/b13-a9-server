# 🎓 MediQueue Server

Backend RESTful API for MediQueue platform built with Node.js, Express.js, and MongoDB. Handles tutor listings, session bookings, and user-specific data management.

🔗 **Live Server API:** [https://findouttutors.vercel.app/](https://findouttutors.vercel.app/)  
📁 **Server Repository:** [https://github.com/durjoy1516/b13-a9-server](https://github.com/durjoy1516/b13-a9-server)

---

## ✨ Features & Endpoints

- **Tutors Management:** Endpoints for fetching, creating, updating, and deleting tutor listings (`/tutors`).
- **Bookings Management:** Endpoints for creating and retrieving user-specific bookings (`/bookings`).
- **CORS Configured:** Secure cross-origin resource sharing setup for client-side integration.
- **MongoDB Integration:** Reliable data persistence with custom CRUD operations.

---

## 🛠️ Tech Stack

- **Framework:** Node.js, Express.js
- **Database:** MongoDB
- **Hosting:** Vercel
